# 작업 인계 지침 예시

Resume Board 작성자의 `AGENTS.md`에서 작업 인계 관련 규칙을 발췌·정리한 예시입니다. 대상 프로젝트의 `AGENTS.md`에 필요한 내용을 병합해 사용하세요.

## 작업 진행과 인계

- 사용자가 승인한 작업 범위와 완료 조건을 기준으로 진행한다. 여러 작업은 사용자가 지정한 순서와 우선순위를 따른다.
- 중요한 단계가 끝나거나, 작업을 중단하거나, 세션을 인계하기 전에 현재 프로젝트의 `HANDOFF.md`를 갱신한다. 기존 파일이 있으면 먼저 읽고 기존 형식과 유효한 정보를 보존한다.
- `HANDOFF.md`에는 다음 항목을 기록한다.
  - 작업 목표와 완료 조건
  - 완료한 작업과 변경 파일
  - 주요 결정과 이유
  - 실행한 검증과 결과
  - 진행 중인 부분
  - 남은 작업 순서
  - 다음 실행 명령
  - 막힌 사항
- 새 세션이나 컨텍스트 압축 후에는 `HANDOFF.md`, 실제 파일, Git 상태를 확인한 뒤 작업을 이어간다. 기록과 실제 상태가 다르면 확인된 실제 상태를 기준으로 기록을 수정한다.
- 승인된 범위 안의 일반적인 구현 선택은 스스로 판단한다. 사용자 답변이나 추가 승인이 필요한 경우 이유를 기록하고, 답변에 의존하지 않는 승인된 작업은 계속 진행한다.
- 완료한 작업과 남은 작업을 명확히 구분한다. 검증하지 않은 결과를 성공으로 기록하지 않으며, 모든 요청 작업이 완료되면 결과와 검증 내용을 기록한다.
- 비밀번호, 토큰 등 비밀 정보는 기록하지 않는다.
- 이 지침은 모델, 권한, 샌드박스, 자동 압축 설정의 변경이나 새 세션 실행을 승인하지 않는다. 별도 요청 없이 세션 자동 재시작이나 무한 반복을 구성하지 않는다.

## HANDOFF.md 형식

[README의 인계 파일 예시](../README.md#인계-파일-예시)를 기준으로 작성한다. 각 항목은 Markdown 제목으로 구분하고, 실행 명령은 코드 블록에 기록한다. 남은 작업이나 막힌 사항이 없으면 `없음`으로 명시한다.
